# Support

Questions about using the SDK and reports of bugs belong in the
[issue tracker](https://github.com/Open-Transaction-Layer/otl-sdk/issues), where
the bug report form asks for what is needed to reproduce a problem. Maintainers
answer as time allows and make no commitment to a response time.

A security problem must not be filed as an issue. Report it privately as
described in [SECURITY.md](SECURITY.md).

Questions about the OTL specification itself belong in the
[`otl-specifications`](https://github.com/Open-Transaction-Layer/otl-specifications)
repository, since this repository only implements it.
